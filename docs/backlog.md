# 백로그 (아이디어)

아직 이슈가 아닌 아이디어를 모아 두는 곳이다. 흐름은 [작업 흐름](workflow.md)을 따른다.

- 한 줄로 적는다. 필요하면 짧은 메모를 덧붙인다
- 하기로 정하면 이슈로 승격하고(기능·개선 또는 버그 템플릿) 여기서 지운다
- 30일 넘게 움직임이 없는 이슈는 닫거나 여기로 강등한다

## 아이디어

- **XL 홈 화면에 더 많이 담기** — XL은 콘텐츠 칸이 25개라 프로젝트 옆에 사용량·주요 세션을 함께 둘 여유가 있다. 무엇을 둘지는 실물 XL을 써 본 뒤 정한다 (#7 이후)
- **XL 장면·게임 중 남는 키 활용** — 장면·게임은 왼쪽 위 5×3만 쓰고 나머지 14키는 비운다. 요약 키 유지, 상시 "뒤로" 키 등 (#7 이후)
- **두 기기 동시 연결 시 우선순위** — 지금은 293S와 XL이 함께 연결되면 어느 쪽도 열지 않는다. `STREAMDOCK_MODEL`이나 마지막 사용 기기를 우선하는 방법 (#17 리뷰)
- **마지막 감지 기기 기억** — 앱을 다시 시작하면 연결 전 미리보기가 293S로 돌아간다. 설정에 마지막 모델을 저장 (#17 리뷰)
- **Swift `--simulate`의 모델 선택** — 시뮬레이터 도우미가 항상 293S USB ID를 보고한다 (#17 리뷰)
- **`device.error` 가리기** — 드라이버 오류 문구가 상태 API에 그대로 나간다. 진단 복사 보고서처럼 경로·토큰을 가린다 (#24)
- **XL RGB LED** — XL의 LED 6개(`LBLIG`·`SETLB` 명령). 상태 색 표시 등에 쓸 수 있다
- **로커 오른쪽 누르기 동작** — 지금은 비워 두었다 (#18)
