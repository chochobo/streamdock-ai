# 워크트리와 정리 미리보기

기능 화면에서 워크트리와 Mole·휴지통의 대상을 확인할 수 있습니다. **현재 앱의 정리 실행은 차단돼 있습니다.** 대상 검사 뒤 파일이 바뀌는 경우에도 승인한 대상만 삭제하는지 검증하지 못했기 때문입니다. 미리보기에서 확인 항목을 선택해도 파일은 삭제되지 않습니다.

워크트리는 명시된 로컬 저장소만 검사합니다. 잠금, 변경·미추적 파일, 무시된 파일, 기준 브랜치 병합 여부와 열린 세션 정보를 확인합니다. `검토 가능`은 당시 검사 조건에 맞는다는 뜻이며 삭제 권한이나 실행 가능 표시가 아닙니다. 기준 브랜치는 로컬 기록으로 확인하며 네트워크 fetch는 하지 않습니다. 열린 세션을 모두 확인할 수 없으면 이를 미확인으로 남깁니다.

Mole 미리보기는 `mo clean --dry-run`, `mo purge --dry-run`을 사용합니다. Mole의 `clean --dry-run`은 후보 목록을 `~/.config/mole/clean-list.txt`에 쓰며 기존 미리보기 파일을 바꿀 수 있습니다. 검사 결과가 불완전하거나 권한이 없으면 확정하지 않습니다. 실제 `mo clean`은 미리보기 뒤 대상을 다시 찾고, 설치된 Mole 버전은 홈 휴지통을 포함할 수 있습니다. 이 앱은 `mo clean`이나 `mo purge --yes`를 실행하지 않습니다.

휴지통 미리보기는 현재 사용자의 홈 `~/.Trash`만 확인합니다. 외장 볼륨의 휴지통은 포함하지 않으며, 목록을 읽을 권한이 없거나 검사가 불완전하면 미확인으로 표시합니다. 이 앱은 휴지통 항목을 삭제하지 않습니다.

정리가 필요하면 검토한 대상과 현재 상태를 사용자가 직접 확인한 뒤 적절한 도구에서 진행하세요. [Mole 안전 안내](https://github.com/tw93/Mole#safety)
