# 293S 기능 사용 안내

## 화면 이동

프로젝트 첫 화면은 15개 키를 다음과 같이 사용합니다.

```text
[프로젝트] [프로젝트] [프로젝트] [프로젝트] [프로젝트]
[프로젝트] [프로젝트] [프로젝트] [프로젝트] [프로젝트]
[프로젝트] [기능]     [사용량]   [이전]     [다음]
```

`기능`을 누르면 기능 목록이 열립니다. 목록의 `이전`, `다음`, `뒤로`로 화면을 이동합니다. `사용량`은 계정 한도 화면으로 바로 이동합니다. 프로젝트를 누르면 해당 프로젝트의 세션 목록이 나옵니다. 오른쪽 긴 화면은 세 개의 **표시 전용** 영역이며 버튼 입력을 받지 않습니다. Mac 앱의 `기기` 화면에서도 미리보고 키를 누를 수 있습니다.

기본 프로젝트 화면은 열려 있다고 확인된 상위 세션을 우선 표시합니다. `기능` → `기록`에서 이전 기록과 열림 여부를 확인하지 못한 세션을 볼 수 있습니다. 기록 화면의 `열림`을 누르면 기본 화면으로 돌아갑니다. 열려 있다는 것은 작업 중이라는 뜻이 아닙니다. 상태를 확인할 근거가 부족하면 `미확인`으로 표시합니다.

- `요약`: 확인된 열린 상위 세션과 사용량을 표시합니다. `?`는 추정이 포함됐다는 뜻입니다. 사용 속도는 사용률, 정확한 리셋 시각과 기간을 모두 확인할 수 있을 때만 표시합니다. 한도 여유 비교도 같은 기간의 유효한 계정 값이 둘 이상 있을 때만 표시합니다.
- `에이전트`와 `기록`: 확인된 열린 세션과 과거 기록을 따로 봅니다. [세션 안내](focus.md)를 참고하세요.
- XL의 오른쪽 열 위 세 키(요약)는 눌러서 이동합니다. 맨 위는 에이전트 목록, 가운데는 확인 대기 세션 열기(여럿이면 누를 때마다 다음 세션), 아래는 사용량 화면입니다.
- `머신`: 이 Mac에서 읽은 CPU·메모리·디스크 상태를 표시합니다. 확인된 외장 드라이브의 이름, 사용률과 남은 용량도 표시합니다. 드라이브 목록을 모두 확인하지 못하면 `일부 미확인`이 나옵니다. 읽지 못한 값은 `미확인`입니다.
- `타이머`: 5·10·15·20·25·30·45·50·60·90분 키를 눌러 시작합니다. 일시정지·계속·초기화를 지원합니다.
- `게임`과 `장면`: 원하는 항목을 눌러 기기 화면을 전환합니다. 효과음과 자동 화면보호기는 기본적으로 꺼져 있으며 `기능` → `설정`에서 켤 수 있습니다.
- `워크트리`: 확인된 로컬 Git 상태를 보여줍니다. 읽기 범위와 결과는 저장소·열린 세션의 확인 가능 여부에 따라 제한됩니다.
- `설정` → `키 시험`: 키마다 위치 번호·행/열·기기 슬롯 번호를 그리고 누른 키를 표시합니다. 맨 아래 오른쪽 키를 1.2초 이상 누르면 설정으로 돌아갑니다. 확인 방법은 [기기 검증 기록](device-validation.md#키-시험-화면)에 있습니다.

## 머신 그래프

머신 키의 숫자와 막대는 같은 비율을 표시합니다. CPU는 모든 코어의 사용자와 시스템 사용률 합계입니다. 측정 시점과 간격이 다르면 활성 상태 보기와 수치가 다를 수 있습니다. 메모리의 `약`은 물리 메모리 사용량의 추정치라는 뜻입니다. macOS `vm_stat`의 사용 가능 페이지와 파일 기반 페이지를 전체 메모리에서 빼서 계산합니다. 활성 상태 보기와 근접하지만 Apple의 계산 방식이 공개되어 있지 않아 항상 일치한다고 보장할 수 없습니다. 메모리 키에는 추정 사용량을 GB와 사용률로 함께 표시합니다. 상세에는 추정 사용량과 전체 용량을 표시합니다. GB는 1,024³바이트 기준입니다. 디스크는 해당 볼륨의 사용률이며, `df`의 용량 계산을 따릅니다. 값을 읽지 못하면 `미확인`, 이전에 읽은 값은 `이전`으로 표시합니다.

머신 화면을 열면 CPU와 메모리는 약 1초마다 갱신합니다. CPU 사용률은 최초 진입 때 약 250ms 동안 측정하고, 이후에는 직전 표본과의 간격을 기준으로 계산합니다. 디스크·배터리·네트워크는 약 5초, 외장 드라이브는 약 15초, Mole 건강 점수와 온도는 약 60초마다 확인합니다. 느린 검사가 끝날 때까지 CPU 갱신을 기다리지 않습니다. 값을 아직 읽는 중이거나 수집에 실패했거나 유효 기간이 지났으면 해당 값은 `미확인`으로 표시합니다. 머신 화면을 벗어나면 정기 수집을 멈춥니다.

## 게임과 장면

게임은 두더지 잡기, 순서 기억, 짝 맞추기, 슬롯, 블랙잭, 포커, 레이스 7종입니다. 게임 화면의 윗줄 두 줄은 게임판입니다. 아래 줄의 `게임 메뉴`와 `진행` 키는 게임에 따라 메뉴 또는 진행 동작을 합니다. 게임 코인은 앱 안에서만 쓰는 가상 점수입니다.

장면은 수족관, 벽난로, 비, 해변입니다. 장면의 키를 누르면 장면별 효과가 나옵니다. **실제 293S에서 장면을 끝내려면 맨 아래 오른쪽 키를 1.2초 이상 누른 뒤 놓습니다.** Mac 앱의 `기기` 화면에도 종료 방법이 표시됩니다. 자동 화면보호기는 기본적으로 꺼져 있으며 설정에서 대기 시간과 장면을 고를 수 있습니다.

게임과 장면에는 Python 3와 Pillow가 필요합니다. 다음 명령으로 현재 환경을 확인하세요.

```sh
python3 -c "import PIL; print(PIL.__version__)"
```

이 기능들은 AgentDeck의 일부 코드를 포함합니다. 저작권과 허가 조건은 [포함된 MIT 라이선스](../src/vendor/agentdeck/LICENSE)에 있습니다. 이식 후 전체 게임·장면과 길게 누르기의 실물 동작은 아직 모두 검증하지 않았습니다.

## 시세와 관심 목록

`주식` 화면에서 보기 전환 키로 코스피, 코스닥, 업종 등락, 포트폴리오, 관심 업종, 거시 지표와 지수를 선택합니다. 네이버 금융의 **비공식 공개 데이터**를 읽으며, 제공자의 거래 시각과 수집 시각은 다릅니다. 장이 닫혔거나 시세가 지연될 수 있습니다. 읽기에 실패한 값은 `미확인` 또는 `오래됨`으로 표시합니다. `HeatTab` 키는 누를 때만 기본 브라우저를 엽니다.

포트폴리오와 관심 업종은 자동으로 추측하지 않습니다. 앱 폴더에서 아래 예제를 복사한 다음 직접 편집하세요.

```sh
mkdir -p "$HOME/.config/streamdock-ai"
cp examples/market.example.json "$HOME/.config/streamdock-ai/market.json"
chmod 600 "$HOME/.config/streamdock-ai/market.json"
```

`portfolio`에는 네이버에서 조회할 종목 코드를 최대 10개, `favoriteSectors`에는 업종 이름을 최대 10개 입력합니다. 예시의 빈 배열은 아무것도 조회하지 않습니다. 포트폴리오 화면에 들어가면 전송할 종목 코드를 먼저 보여줍니다. **전송 확인 전에는 해당 종목 코드를 네이버에 보내지 않습니다.** 확인 후 그 화면에 머무는 동안 60초마다 다시 조회합니다. 화면을 벗어나면 다시 확인해야 합니다.

## 택배

택배는 기본적으로 설정되지 않습니다. 다른 앱의 주문이나 운송장을 자동으로 가져오지 않습니다. 전용 브라우저에서 직접 연 AliExpress 배송 탭의 번호를 미리보기로 가져오는 선택형 방식은 [가져오기 안내](parcel-import.md)에 있습니다. 직접 등록할 때는 예제를 복사해 편집하세요.

```sh
mkdir -p "$HOME/.config/streamdock-ai"
cp examples/parcels.example.json "$HOME/.config/streamdock-ai/parcels.json"
chmod 600 "$HOME/.config/streamdock-ai/parcels.json"
```

`parcels` 배열에 `tracking`과 `title`을 넣고, 외부 배송 조회를 사용하려면 `trackingOptIn`을 `true`로 설정합니다. 설정만으로 전송하지는 않습니다. 조회를 선택한 뒤 Mac 앱의 `요청 검토`에서 **보낼 운송장 전체 목록**을 확인하고, 기기의 확인 키를 길게 눌러야 Cainiao에 전송합니다. 목록이 변경되거나 확인이 만료되면 다시 검토해야 합니다. 운송장 번호는 기본 상태 API와 로그에 출력하지 않습니다.

예상일은 배송 서비스가 제공한 값만 표시합니다. 배송 단계만으로 날짜를 만들어 표시하지 않습니다. 조회에 실패하면 이전 값 또는 확인 불가 상태를 표시합니다.

## 원격과 크레딧

원격 기능은 기본적으로 꺼져 있습니다. 설정 파일을 직접 만들고, 허용할 호스트와 조회 항목을 지정해야 합니다. 조회는 대상을 선택하고 한 번 더 확인할 때만 실행합니다. SSH 키·호스트 키 조건과 설정 예제는 [원격 안내](remote.md)를 참고하세요. 테스트 또는 설정 확인만으로 원격 서버에 접속하지 않습니다.

크레딧은 연결하지 않은 서비스를 `설정 필요`로 표시합니다. `examples/credits.example.json`은 모든 서비스를 끈 상태입니다. 인증 정보와 브라우저 프로필을 임의로 가져오지 않습니다. 사용자가 별도 수집 방식을 명시한 경우의 조건은 [크레딧 안내](credits.md)에 있습니다.

## 정리와 업데이트

머신 정리·휴지통·워크트리 제거는 대상을 미리 볼 수 있지만, **실제 삭제 실행은 안전성 검증 전까지 비활성화**돼 있습니다. 미리보기의 예상 크기는 실제 확보 용량이 아닙니다. Mole 정리 미리보기는 Mole 자체의 후보 목록 파일을 갱신할 수 있습니다. 자세한 내용은 [정리 안내](cleanup.md)를 확인하세요.

업데이트는 기본적으로 꺼져 있습니다. 신뢰할 저장소와 브랜치를 설정한 뒤 사용자가 요청하면 원격 상태를 확인합니다. 변경 내용을 Mac 앱의 `요청 검토`에서 확인하고 기기에서 적용을 선택하면 조건을 다시 확인한 뒤 적용합니다. 패키지 설치와 앱 재시작은 자동으로 하지 않습니다. 현재 작업 폴더는 Git 저장소가 아니므로 업데이트가 설정되지 않은 상태입니다. [업데이트 안내](update.md)를 참고하세요.
