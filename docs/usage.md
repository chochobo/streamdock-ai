# 계정 사용량

Codex와 Claude Code에서 확인한 사용률과 각 한도 창의 리셋 시각을 표시합니다. 사용률은 **사용한 비율**입니다. 데이터가 없으면 `미확인`으로 표시하며 0%로 바꾸지 않습니다.

## 화면 사용법

- Mac 앱의 **에이전트와 사용량** 화면에서 값을 봅니다. **사용량 갱신** 버튼으로 다시 확인할 수 있습니다.
- 293S의 프로젝트 화면에서 맨 아래 줄 세 번째 **사용량** 키를 누릅니다. 사용률 키와 그 오른쪽의 리셋 시각 키가 한 쌍입니다. 한 화면에 다 표시할 수 없으면 **이전**과 **다음**으로 이동합니다.
- 사용량 화면의 **뒤로** 키는 프로젝트 화면으로 돌아갑니다. 사용량·리셋 표시는 정보용이며 누르더라도 한도를 변경하거나 리셋하지 않습니다.

사용량 키의 숫자와 막대는 모두 **사용한 비율**을 나타냅니다. 0%는 빈 막대, 100%는 가득 찬 막대입니다. 확인된 사용률이 60% 미만이면 초록색, 60% 이상 85% 미만이면 노란색, 85% 이상이면 빨간색으로 표시합니다. 값을 읽지 못하면 `미확인`으로 표시하고 0% 막대로 바꾸지 않습니다. 마지막 확인 값만 남아 있으면 `오래됨`으로 구분합니다.

공급자가 제공한 사용 구간만 표시합니다. 예를 들어 Codex가 7일 값만 제공하면 5시간 키는 표시하지 않습니다. 값이 없다는 사실만으로 요금제에 그 한도가 없다고 확정하지는 않습니다. 계정의 사용량 전체를 확인할 수 없으면 `미확인` 키 하나를 표시합니다.

## 수집 방식과 한계

**Codex:** 로컬 Codex CLI의 공식 app-server `account/rateLimits/read`로 해당 CLI 인증 계정의 사용률과 리셋 시각을 확인합니다. CLI에 연결된 계정 하나가 대상입니다. 실행 중인 데스크톱 앱의 계정과 같은지는 별도로 확인해야 합니다. API 키 인증 등에서 구독 한도가 제공되지 않으면 `미확인`으로 표시합니다. 여러 한도 버킷이 제공되면 각각의 창을 구분합니다. [Codex app-server 문서](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)

**Claude Code:** 공식 status line이 전달하는 `rate_limits`를 읽습니다. 지원되는 구독의 첫 응답 뒤에 사용 구간 값이 나타날 수 있으며, 각 값은 없을 수도 있습니다. Claude Code의 status line이 실행될 때만 이 스냅샷이 갱신됩니다. 래퍼 설치 후 실제 사용량이 포함된 입력을 받는지 확인하세요. [Claude Code status line 문서](https://code.claude.com/docs/en/statusline#rate-limit-usage)

**Claude Desktop 대체 경로:** 실행 중인 Claude 앱의 사용량 배지가 보일 때, 주간 사용률과 리셋 문구의 접근성 텍스트를 읽습니다. 대화 내용이나 인증 정보는 읽지 않고, 이 경로에서 네트워크 요청을 직접 보내지 않습니다. macOS 접근성 권한과 현재 앱 버전의 사용량 배지가 필요합니다. 실제 293S에서 주간 사용률과 리셋 문구가 Claude 화면과 일치하고, 제공되지 않은 구간은 표시되지 않는 것을 확인했습니다. 앱이 날짜 없이 요일과 시각만 표시하면 그 문구를 그대로 표시하며 날짜는 추정하지 않습니다. 계정 식별이 확인되지 않아 `계정 미확인`으로 표시합니다.

스냅샷에는 신뢰할 수 있는 계정 식별자가 보장되지 않으므로 **계정 미확인**으로 표시합니다. 기존 AgentDeck 스냅샷이 있으면 별도 출처로 표시할 수 있지만, 서로 다른 계정이라는 뜻은 아닙니다. 현재 구현은 여러 Codex 또는 Claude 계정을 각각 인증하고 조회하는 기능을 제공하지 않습니다.

## 갱신과 오래된 값

앱은 사용량 수집을 시작할 때와 이후 60초마다 시도합니다. 수동 갱신은 15초 안에 반복하면 직전 결과를 재사용합니다. 이는 수집 시도 주기이며, Claude Code가 새 사용량 값을 제공하는 주기와는 다릅니다.

확인 시각은 원본 값의 최신성을 판단하는 데 사용합니다. Claude Desktop의 배지가 보이지 않거나 읽기에 실패하면 이전 값을 `오래됨`으로 표시한 뒤 사용할 수 없으면 `미확인`으로 표시합니다. Claude status line 스냅샷은 마지막 관측에서 15분이 지났거나 리셋 시각이 지났으면 `오래됨`으로 표시합니다. Codex 조회가 실패하면 마지막 확인 값을 최대 24시간 동안 `오래됨`으로 표시할 수 있습니다. 시간이 지난 값이나 리셋 예정 시각을 현재 사용률로 추정하지 않습니다.

## Claude status line 설정과 개인정보

수집 래퍼는 기존 `~/.claude/settings.json`의 statusLine 명령을 유지합니다. 기존 설정이 있으면 설치 시 원본을 `~/.claude/settings.json.usage-backup-*` 형식의 파일에 백업하고 실제 백업 경로를 출력합니다.

수집 래퍼는 사용률·리셋 시각과 관측 시각만 `~/.cache/streamdock-ai/usage/claude-statusline.json`에 저장합니다. 새 파일은 `0600` 권한으로 만듭니다. 사용량 수집기 코드는 OAuth 토큰이나 API 키 원문을 읽거나 저장하지 않습니다. Codex의 인증 처리는 Codex app-server가 담당합니다.

래퍼를 제거하고 기존 statusLine 설정을 복원하려면 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
node scripts/install-usage-statusline.mjs --remove
```

설치 후 statusLine 설정을 따로 바꿨다면 제거기는 변경 사항을 덮어쓰지 않고 중단합니다. 이 경우 현재 설정과 백업을 확인하세요. 자세한 내용은 [Claude Code 사용량 연결](usage-statusline.md)을 참고하세요.
