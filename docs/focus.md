# 세션 열기

프로젝트의 세션 키를 누르면 세션의 저장된 대상 정보를 사용해 화면 열기를 요청합니다. 확인할 수 없는 대상은 실패로 표시합니다. 키를 눌러도 메시지를 전송하거나 권한 요청을 승인하지 않습니다.

2026년 11월 9일 사용자가 실제 293S의 프로젝트·세션 화면과 현재 Codex 채팅 및 활성 Claude 세션 이동을 확인했습니다. 이후 Claude의 현재 계정·유일 조직 필터를 적용하고, 다른 Claude 채팅에서 버튼과 같은 앱 API로 기존 세션을 선택해 정확한 채팅으로 전환되는 것을 확인했습니다. 이 시험은 선택한 세션에 한정되며 모든 계정과 세션에 대한 보장은 아닙니다.

Codex 데스크톱 세션은 설치된 ChatGPT 앱에서 사용하는 `codex://threads/<채팅 ID>` 형식으로 열기를 요청합니다. 이 형식은 현재 앱의 내부 구현에서 확인했으며 공개된 안정 API로 검증되지는 않았습니다. OS가 요청을 받았다는 사실만으로 실제 채팅 전환을 보장할 수 없습니다. 원격 세션은 지원하지 않습니다.

Claude 데스크톱 세션은 현재 계정과 유일한 조직 폴더가 일치하고, 로컬 인덱스에서 CLI 세션과 데스크톱 세션이 정확히 하나로 연결되며 보관되지 않은 경우에만 `claude://code/continue?session=<데스크톱 ID>`로 열기를 요청합니다. 이 형식도 현재 설치된 앱의 내부 구현이며, OS 요청 성공은 실제 화면 전환 성공과 다릅니다. 현재 계정으로 추정되는 계정과 하나로 식별되는 조직에 연결된 세션만 대상으로 합니다. 계정이나 조직이 모호하면 데스크톱 이동을 지원하지 않습니다. 필터 적용 전 다른 계정의 과거 세션을 시험했을 때 기존 세션 대신 새 세션 화면이 나타난 사례가 있었습니다. 필터는 확인된 다른 계정의 항목을 제외하고 계정 또는 조직이 모호하면 이동을 막습니다. 딥링크가 공개된 안정 API는 아니므로 OS가 요청을 수락했더라도 의도한 세션이 열렸는지 확인해야 합니다.

Claude Code 및 Codex CLI를 Apple Terminal이나 iTerm2에서 실행하는 경우에는 세션 훅에 연결된 프로세스 ID, 프로세스 시작 시각, TTY, 앱을 확인합니다. 현재 살아 있는 프로세스와 일치하고, 해당 TTY를 사용하는 탭이 하나뿐일 때만 그 탭을 선택합니다. macOS 자동화 권한이 필요할 수 있습니다. 프로세스가 끝났거나 식별 정보가 없거나 여러 탭이 일치하면 열지 않습니다. VS Code, Cursor, Ghostty, 원격 세션은 정확한 채팅이나 탭 이동을 지원하지 않습니다.

세션 ID와 터미널 경로는 연결을 위해 이 Mac의 앱 내부에서 사용합니다. 표시용 API에는 이 값을 넣지 않습니다. 프롬프트와 답변 내용은 이 기능에 필요하지 않습니다.

대상 정보가 불충분하면 앱은 자동 재개 명령이나 새 세션 생성 명령을 실행하지 않습니다. 딥링크를 받은 외부 앱이 예상과 다른 화면을 표시할 수는 있으므로, 선택된 채팅을 확인하세요.
