# 소스 업데이트

업데이트는 기본적으로 꺼져 있습니다. 현재 프로젝트가 Git 저장소가 아니거나 신뢰한 원격 주소가 설정되지 않으면 `not_configured`로 표시합니다. 자동 fetch와 자동 업데이트는 하지 않습니다.

업데이터를 연결하려면 앱 저장소의 최상위 경로, 브랜치와 신뢰할 HTTPS `origin` 주소를 명시해야 합니다. 주소에 비밀번호나 토큰을 넣을 수 없습니다. 기존 origin과 다르거나 Git URL 변환·로컬 필터가 있으면 중단합니다.

선택적으로 `~/.config/streamdock-ai/update.json`을 만들 수 있습니다. 아래 주소는 예시이며 실제로 신뢰하는 origin 주소로 바꿔야 합니다.

```json
{"enabled": true, "remoteUrl": "https://github.com/OWNER/REPO.git", "branch": "main"}
```

파일이 없거나 `{"enabled": false}`이면 기능은 꺼집니다. `readUpdateConfig()`는 설정만 읽고 네트워크에 접속하지 않습니다. 비밀번호, 토큰, URL 쿼리, 알 수 없는 필드, 심볼릭 링크는 허용하지 않습니다. 실제 원격 조회는 사용자가 요청할 때만 합니다. 로컬 Git HTTP 인증 또는 프록시 설정이 있는 저장소는 업데이트를 중단합니다.

`check()`는 로컬 정보만 읽습니다. 사용자가 원격 확인을 선택하면 `check({remote:true})`가 설정된 HTTPS 원격 브랜치만 조회합니다. `prepare()`는 사용자가 요청한 경우에만 변경 객체를 받아 전체 diff와 파일 목록을 만듭니다. 브랜치나 작업 파일을 바꾸지 않습니다.

`apply(token)`은 검토한 일회성 토큰이 있을 때만 실행합니다. 작업 트리가 깨끗한지, 같은 브랜치·원격·커밋·diff인지, fast-forward가 가능한지 다시 확인합니다. 실패하면 강제 변경이나 초기화를 하지 않습니다. 성공하면 HEAD를 확인합니다. 패키지 설치와 앱 재시작은 자동으로 하지 않습니다.

이 기능은 아직 실제 원격 저장소에 연결하거나 업데이트하지 않았습니다. 테스트는 가짜 Git 실행기를 사용합니다. Git 인증이 필요한 원격은 대화형 로그인 없이 실패할 수 있습니다.
